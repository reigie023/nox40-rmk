# RMK firmware for nox40

RMK 0.8.2 のローカルビルド用に、nox40向け差分ファイルとバイナリを置いておきます。Releasesからダウンロードしてください。
初めてRMKなので手探りで調整したものですが、不十分であればご自身で差分ファイルからご自身でビルドしてください。

RMKはXMKと比較して以下の点でメリットがあります。

' ZMK StudioではサポートされていないコンボやタップダンスがVialを使ってGUIで設定できます。
' どうやらZMKよりも省電力的には優秀という話がありますが、まだ十分使いこんでいないので実感としてはわかりません。

こちらで確認している問題点は

' 接続先の切替は結構時間がかかります。  
　切替キーを押してから実際に切り替わるまで数秒かかるので、焦らず待てば切り替わります。
' まあまあ安定しているとは思うのですが、BLE接続時にたまにチャタリングが起きることがあります。
